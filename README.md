# AI-rings-PublicVersion

Public version of the interactive map of AI money flows: who funds whom, and where to watch. Content mirrors the internal `AI-rings` repo, without internal annotations.

Live site: `https://jb-db05.github.io/AI-rings-PublicVersion/`

## Files

- `index.html` is the whole site. HTML, CSS, JS and the logo (base64) are all in this one file.
- `.nojekyll` tells GitHub Pages to serve the files as they are, without running Jekyll.
- `UPDATING.md` covers how to edit the page and publish the changes.

## Publishing

GitHub Pages publishes the `main` branch, from `/ (root)` (set under **Settings → Pages**). Anything pushed or merged into `main` goes live after about a minute.

## Keeping it in sync with the internal version

Content edits are made in the internal `AI-rings` repo first, then copied here with internal annotations removed.
